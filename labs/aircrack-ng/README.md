# Aircrack-ng Guide And Local Wireless-Capture Fixture Lab

This lab teaches `aircrack-ng` with a local offline IV fixture generated by
`makeivs-ng`. You can practice tool discovery, capture fixture creation, IVS
merging, BSSID targeting, WEP key recovery, and output review without using a
wireless adapter or touching any real Wi-Fi network.

Aircrack-ng is a wireless assessment suite. Live capture and injection can
disrupt networks and may be illegal without explicit authorization. This lab is
offline by design: it creates a synthetic toy IVS file inside Docker and cracks
the known demo key `ABCDE`.

## Safety Rules

- Assess only wireless networks and captures you own or have explicit permission to test.
- Do not capture, deauthenticate, inject, crack, or share real wireless traffic outside scope.
- Treat wireless captures, recovered keys, and wordlists as sensitive data.
- Use monitor mode and packet injection only in an authorized lab with clear channel and power limits.
- Keep this lab offline unless your authorization covers a real capture or test network.
- Never use recovered keys to access a network without permission.

## Lab Topology

This Compose lab uses one scanner container and local mounted outputs. It does
not require a Wi-Fi adapter and does not create radio traffic.

| Container | Purpose |
| --- | --- |
| `scanner` | Runs `aircrack-ng`, `makeivs-ng`, `ivstools`, and `airdecap-ng`. |

Mounted lab directories:

| Directory | Purpose |
| --- | --- |
| `outputs` | Generated IVS fixtures, crack output, validation files, and summaries. |

## Start The Lab

Run from the repository root:

```bash
docker compose -f labs/aircrack-ng/docker-compose.yml up --build -d
docker compose -f labs/aircrack-ng/docker-compose.yml ps
docker compose -f labs/aircrack-ng/docker-compose.yml exec scanner aircrack-ng --help
```

Clean up when finished:

```bash
docker compose -f labs/aircrack-ng/docker-compose.yml down
```

## Local Fixture

The helper generates a toy WEP IVS fixture with these values:

| Item | Value |
| --- | --- |
| BSSID | `02:11:22:33:44:55` |
| WEP key hex | `41:42:43:44:45` |
| WEP key ASCII | `ABCDE` |

This is intentionally weak, synthetic, and local. It is only for learning the
Aircrack-ng workflow.

## Basic Usage

Generate a local IVS fixture:

```bash
docker compose -f labs/aircrack-ng/docker-compose.yml exec scanner \
  makeivs-ng -b 02:11:22:33:44:55 -k 4142434445 \
  -w outputs/toy-left.ivs -c 100000 -s 7
```

Generate a second fixture and merge them:

```bash
docker compose -f labs/aircrack-ng/docker-compose.yml exec scanner \
  makeivs-ng -b 02:11:22:33:44:55 -k 4142434445 \
  -w outputs/toy-right.ivs -c 100000 -s 8

docker compose -f labs/aircrack-ng/docker-compose.yml exec scanner \
  ivstools --merge outputs/toy-left.ivs outputs/toy-right.ivs outputs/toy-merged.ivs
```

Crack the toy WEP fixture:

```bash
docker compose -f labs/aircrack-ng/docker-compose.yml exec scanner \
  aircrack-ng -a 1 -b 02:11:22:33:44:55 -n 64 -q \
  -l outputs/cracked-key.txt outputs/toy-merged.ivs
```

Expected result:

```text
KEY FOUND! [ 41:42:43:44:45 ] (ASCII: ABCDE )
```

## Useful Options

| Option | Use |
| --- | --- |
| `aircrack-ng` | Crack WEP/WPA captures offline. |
| `makeivs-ng` | Generate synthetic IVS test files for offline practice. |
| `ivstools --merge` | Merge IVS files. |
| `airdecap-ng` | Decrypt supported capture files when you have the key. |
| `-a 1` | Force WEP attack mode. |
| `-b BSSID` | Select the access point MAC address. |
| `-n 64` | Set 64-bit WEP key length. |
| `-q` | Quiet output for repeatable logs. |
| `-l FILE` | Write the recovered key to a file. |
| `-w FILE` | Use a wordlist for WPA-PSK captures. |

## Generate Practice Outputs

Run a quick Aircrack-ng workflow:

```bash
sh labs/aircrack-ng/make_scans.sh
```

This writes help/version output, generated IVS fixtures, merged IVS output, WEP
crack output, a wrong-BSSID comparison, validation results, and a TSV summary
into `labs/aircrack-ng/outputs`.

## Practice Tasks

1. Run `aircrack-ng --help` and identify WEP and WPA options.
2. Generate `toy-left.ivs` and inspect its size.
3. Merge two IVS files with `ivstools --merge`.
4. Crack `toy-merged.ivs` and confirm the recovered key is `41:42:43:44:45`.
5. Change the BSSID in the crack command and compare the failure output.
6. Inspect `outputs/validation.tsv` after running the helper.
7. Write a safe Aircrack-ng command for a capture you are authorized to audit.

## Live Wireless Note

Live wireless capture usually needs a compatible Wi-Fi adapter, monitor mode,
local regulatory compliance, and explicit authorization. Docker on macOS does
not provide direct access to host Wi-Fi hardware, so this lab intentionally
does not teach live capture or packet injection commands.

## Troubleshooting

If the crack does not find the key, rerun the helper to regenerate the local
fixture:

```bash
sh labs/aircrack-ng/make_scans.sh
```

If `aircrack-ng` cannot read the IVS file, confirm it exists:

```bash
ls -lh labs/aircrack-ng/outputs/*.ivs
```

If Compose reports a stale scanner, restart the lab:

```bash
docker compose -f labs/aircrack-ng/docker-compose.yml down
docker compose -f labs/aircrack-ng/docker-compose.yml up --build -d
```
